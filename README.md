# PES1UG24CS192 – Software Engineering Lab Submissions

This repository contains the Software Engineering Lab 1, Lab 2, Lab 3, Lab 4, and Lab 5 work for SRN **PES1UG24CS192**.

## Contents

- **Lab 1** – Requirements, use-case specification, and diagrams
- **Lab 2** – Jira evidence, documentation, and screenshots
- **Lab 3** – Component diagram and written justification
- **Lab 4** – Balloon Pop game: bug fixes, new balloon types, scoring system, lives, countdown timer, and restart functionality. Includes before and after demonstration videos.
- **Lab 5** – Static Code Analysis using Pylint, Bandit, and Flake8. Includes identification and fixing of code quality issues, security vulnerabilities, formatting violations, before-and-after analysis reports, and reflection.

Each lab is organized in its own folder for clear submission and evaluation.
